# 两地远程工作方式：Tailscale 组网 + 远程桌面 / 服务直连

> **一句话**：家里和公司各放一台 24 小时开机的电脑，两台电脑通过 Tailscale 组成加密虚拟局域网。无论人在家还是在公司，都能远程使用另一台电脑上的服务，也能远程控制它的桌面，体验和坐在那台电脑前基本一致。

---

## 一、场景概述

- **家里**：一台 24 小时运行的 Windows 电脑（如跑闲鱼自动回复系统等自动化服务）
- **公司**：一台长期运行的电脑（Mac / Windows 均可）
- **核心诉求**：人在任何一地，都能
  1. 访问另一台电脑上运行的 Web 服务（管理后台、监控页面等）
  2. 远程控制另一台电脑的桌面，完成任何需要完整操作系统的任务

---

## 二、总体架构

Tailscale 基于 WireGuard 组建虚拟局域网（tailnet），每台设备分配一个固定的 `100.x.x.x` 内网 IP，NAT 穿透直连，不需要公网 IP、不需要路由器端口转发，流量全程加密。

```text
        家里                        Tailscale 虚拟内网                      公司
┌──────────────────┐          （WireGuard 加密隧道）          ┌──────────────────┐
│ 24h Windows 电脑  │  ◄──────────────────────────────────►  │ 长期运行的工作电脑  │
│ Tailscale 100.x.a │   互访：服务端口 + 远程桌面端口           │ Tailscale 100.x.b │
│ 跑着后台服务:9000 │                                          │                  │
└──────────────────┘                                          └──────────────────┘
        ▲                                                            ▲
        │                                                            │
   人在公司时远端访问它                                          人在家时远端访问它
```

- 每台设备只需安装 Tailscale 并登录**同一账号**，即自动组网
- 设备数不限于两台，手机装 Tailscale App 后同样可以随时接入

## 三、方式一：Tailscale + 系统自带远程桌面（推荐，更安全）

适合需要**完整桌面操作**的场景（跑脚本、操作软件、处理弹窗验证等）。

**前提**：家里电脑是 **Windows 专业版**（家庭版没有 RDP 服务端，见下方替代方案）。

**步骤**：

1. 家里电脑开启远程桌面：
   - 设置 → 系统 → 远程桌面 → 打开「远程桌面」
   - 记下 Windows 用户名和密码（建议单独设一个强密码的账户用于远程登录）
2. 家里电脑和公司电脑都安装 Tailscale 并登录同一账号
3. 公司电脑安装远程桌面客户端：
   - **Mac**：App Store 安装 **Microsoft Remote Desktop**（微软官方免费）
   - **Windows**：系统自带「远程桌面连接」（mstsc）
4. 客户端中添加 PC：
   - 地址填家里电脑的 Tailscale IP（如 `100.x.x.x`）
   - 输入 Windows 用户名和密码，连接

**安全性**：RDP 只监听在 Tailscale 虚拟网卡上，完全不暴露公网，也不对家里局域网其他设备开放，安全性很高。

**家庭版替代方案**：家里是 Windows 家庭版（无 RDP 服务端）时，改用 VNC 类软件：
- **TightVNC**（免费）/ **RealVNC**，同样只绑定 Tailscale 网卡地址
- Mac 端用自带的「屏幕共享」或 RealVNC Viewer 连接

## 四、方式二：Tailscale + 服务直连（浏览器直接访问）

适合只需要用**某个 Web 服务**的场景（看后台、改配置、查数据），比远程桌面更流畅省电。

**原理**：两个电脑上的服务端口（如管理后台 9000）绑定 `0.0.0.0` 后，天然监听所有网卡，Tailscale 组网后另一台设备直接用浏览器访问 `http://100.x.x.x:9000` 即可，无需任何改动。

**示例**（以闲鱼自动回复系统为例）：

| 场景 | 操作 |
|------|------|
| 人在公司，看家里的后台 | 浏览器打开 `http://100.x.x.x:9000` |
| 人在家，看公司的服务 | 浏览器打开 `http://100.x.y.y:端口` |

**优势**：不用传整个桌面画面，只传网页数据，延迟低、流畅，手机上也能操作。

## 五、两台电脑的部署清单

每台常开电脑都需要：

- [ ] 安装 Tailscale（官网下载），登录同一账号
- [ ] 开启 **Run unattended（无人值守）**：任务栏图标 → Preferences → 勾选，保证锁屏/未登录桌面时依然在线
- [ ] **关闭休眠/睡眠**（电源设置，接通电源时从不进入睡眠），休眠会断网离线
- [ ] Windows Update 活跃时段设为工作时间，避免白天自动重启
- [ ] 记录本机 Tailscale IP（`tailscale ip -4`）
- [ ] 防火墙收紧：服务端口只允许 Tailscale 网段（`100.64.0.0/10`）访问，不对局域网/公网开放：

```powershell
# 例：只允许 Tailscale 网段访问 9000 端口
New-NetFirewallRule -DisplayName "Admin (Tailscale only)" -Direction Inbound -Protocol TCP -LocalPort 9000 -RemoteAddress 100.64.0.0/10 -Action Allow
```

**可选增强**：
- 在 Tailscale 管理后台开启 MagicDNS，用设备名代替 IP（如 `home-pc.xxx.ts.net`）
- 用 ACL 限制只有指定设备能访问特定端口

## 六、使用场景对照

| 需求 | 用哪个方式 |
|------|-----------|
| 看后台数据、改配置、查消息 | **方式二**（浏览器直连，最流畅） |
| 操作完整桌面：跑软件、处理弹窗/扫码/滑块验证、传文件 | **方式一**（远程桌面） |
| 手机上临时看一眼 | **方式二** + Tailscale 手机 App |
| 人在公司要用家里的专用软件（如只有 Windows 版的工具） | **方式一** |
| 大批量传文件 | 方式一（远程桌面可直接拖拽/共享剪贴板），或 Tailscale 自带的 taildrop / 文件共享 |

日常推荐组合：**方式二为主**（轻量高频），**方式一备用**（需要完整桌面时）。

---

## 七、安全与注意事项

1. **远程桌面/服务只走 Tailscale 内网**，不要图省事做路由器端口映射把 RDP 或后台暴露到公网——公网扫描暴力破解 RDP 是最高发的入侵方式之一
2. Windows 远程登录账户用**强密码**；Web 后台同样改强密码
3. 两台电脑的系统更新保持开启，安全补丁及时打
4. 公司网络如限制安装 VPN 类软件，需先确认合规（此情况下可改用 Cloudflare Tunnel 等方案，另行评估）
5. 家里断网/断电时远程不可用，重要自动化服务可考虑配一个小型 UPS
6. Tailscale 账号本身启用双因素认证（2FA），丢了账号等于丢了整个内网入口
