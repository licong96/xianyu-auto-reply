# 学科网试卷爬虫

- 提交：`9353b53`

## 做了什么

资料池第二步：独立的学科网试卷爬虫 `paper_crawler`，用 DrissionPage 打开真实浏览器。依赖放在 `requirements-crawler.txt`，不写进主项目虚拟环境。

- 人工登录接管：单独端口和用户目录保存登录态，未登录时等待扫码
- 列表页解析标题、属性标签、发布日、下载量
- 详情页补全日期，已登录后点击下载并计算 md5
- `source_url` 和 md5 两道去重，支持断点续爬，单条失败不打断整批
- 结果直接写入 `xy_material_pool`，状态为 `crawled`

主要文件：`paper_crawler/zxxk.py`、`db.py`、`settings.py`、`config.yaml`、`__main__.py`、`README.md`。
