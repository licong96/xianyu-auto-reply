# 网盘文件夹级上架（22 号方案第二阶段）

- 状态：**已实施（2026-10-16）**
- 依赖：[22-网盘浏览与直选上架方案](./22-网盘浏览与直选上架方案.md)

## 背景与目标

22 号方案第一阶段文件夹仅支持「浏览 + 分享」，文件夹级上架预留到第二阶段。本方案补上：网盘管理页对整个文件夹点「上架」，分享与发货的都是**整个文件夹的链接**，导入资料池后走与文件完全相同的审核/一键上架流水线。

## 关键设计决策

### 1. 分享链路零改动

夸克 CLI 的 `share`/`share-list` 本身不区分文件与目录（`first_fid` 反查对目录 fid 同样成立），`create_share(文件夹路径)` 返回的就是文件夹分享链接。后端 `_ensure_share_for_location` 的查重/创建逻辑直接复用。

### 2. 复用 `/pan/import`，新增 `is_dir` 标记

- `PanImportRequest` 新增 `is_dir` 字段；文件夹导入时 `file_size` 传空
- `xy_material_pool` 新增 `is_dir TINYINT(1)` 列（建表 + 自动迁移），资料池列表试卷名旁显示「文件夹」徽章
- 去重语义不变：按路径（`pan://<文件夹路径>`）唯一，文件夹与其内部文件互不冲突
- 文件夹行永远不会误触发上传：`pan_url` 建记录时已就绪，`upload_pool_row_to_pan` 第一关即拒绝

### 3. 前端交互

- 文件夹行操作列与文件一致：「分享」（已有）+「上架」
- 上架弹窗适配：标题默认取目录名（不用去扩展名规则，避免「2026.9 月试卷」被截成「2026」）、网盘勾选标注「整个文件夹」、说明文案提示买家可见文件夹内全部内容
- 资料池一键上架/卡券/续售编排零改动（记录形状与文件一致）

## 数据流（文件夹上架）

```
网盘管理页对文件夹点「上架」
  → 弹窗补信息（标题/售价/描述/封面，发货网盘勾选）
  → POST /pan/import { file_name: 目录名, is_dir: true, locations: [文件夹路径] }
      → 已有记录？返回旧记录（补链）
      → 无分享？对文件夹路径创建分享（链接为整个文件夹）
      → INSERT xy_material_pool（status=pending, is_dir=1）
  → PUT /material-pool/{id} 补信息
  → 资料池审核 → 一键上架（现有 list_to_pan，零改动）
  → 卡券正文 = 文件夹分享链接，买家打开可见文件夹内全部内容
```
