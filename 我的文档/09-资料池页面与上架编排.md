# 资料池页面与上架编排

- 提交：`85927f5`
- 标记：CUSTOM

## 做了什么

资料池第四步：后台页面和上架编排。

后端 `material_pool_service` 提供列表筛选分页、编辑、审核、触发上传网盘，以及一键上架。上架按「建素材 → 发布 → 绑定卡券 → 写续售规则」逐步执行，每步可重试，失败停在 `failed`。

接口前缀 `/api/v1/material-pool`，包含列表、详情、更新、通过、拒绝、上传网盘、上架、批量上架。

前端新增资料池页：筛选表格、复制分享链接、编辑时上传封面、审核弹窗、选择账号后一键上架和批量上架。菜单、路由、标签页标题已接上。

另外修了一处：SQLAlchemy 在 `commit` 之后属性过期，再懒加载会报错。改为先拿到局部变量，需要时 `refresh`，状态更新用 SQL 原子写入。

主要文件：

- `backend-web/app/services/material_pool_service.py`
- `backend-web/app/api/routes/material_pool.py`
- `frontend/src/pages/material-pool/MaterialPool.tsx`
- `frontend/src/api/materialPool.ts`
